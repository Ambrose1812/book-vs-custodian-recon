# Book vs. Custodian Reconciliation Pipeline

Does our book of record match the custodian, and where are the breaks?

## Why this matters
A fund's internal records (the book of record) and its custodian bank's records
should agree on what is owned. Differences are called breaks and need
investigation. This project models that daily process.

## Architecture
OpenFIGI + Tiingo -> Python -> Parquet (landing zone) -> Postgres -> dbt -> Airflow, all in Docker.

Status: only the OpenFIGI ingest is in progress.

## Data sources
- OpenFIGI: real identifier mappings
- Custodian feed: **simulated**, generated by a Python script
- Prices: Tiingo (planned)

## Known limitations
Small simulated scale, data source assumptions not yet verified,
depth prioritized over flash.
